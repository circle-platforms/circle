# Inspector

右侧详情面板：展示列表中选中对象的全部信息和可做的操作；没有选中时展示本区域概况。

## 结构（自上而下，顺序固定）

1. **类型与状态**：类型标签（`ch-tag`）+ 状态标签（`ch-badge`）。
2. **标题**（`ch-panel-title`，18px，可折两行）与事实行：位置与更新时间，例如“接口规范 › 认证 · 今天 10:24 更新”。
3. **来源**：每个来源一块（SourceBlock），先写文件名与位置，再给“打开原文”或“查看”。
4. **分享**：头像与“已分享给李四、王五”；继承文件夹设置时写“同文件夹设置”，旁边是“管理分享”。
5. **使用情况**：例如“近 30 天被引用 3 次”，需要趋势时配迷你柱状图。
6. **版本记录**：最近两三条，写成“张三更新了来源”，完整记录在“版本记录”里打开。
7. **操作**（`ch-inspector-actions`）：贴底，主操作在最右，例如“版本记录 · 分享到团队… · 编辑”。

分区标题用 `ch-section-label`，数量跟在“ · ”后面，例如“来源 · 2”。

## 规则

- 每个区块只出现一次；没有内容的区块不显示，不写“暂无”。
- 不显示哈希、引用编号或版本号；需要核对时给“打开原文”。
- 没有选中对象时显示概况：数量（Stat）、验证情况（分段条）、最近变化。
- 窄屏下详情成为单独一页，顶部用位置返回列表。
