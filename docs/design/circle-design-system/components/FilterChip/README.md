# FilterChip

筛选控件：筛选标签（`ch-chip`）按条件过滤列表，分段选择（`ch-seg`）在几个互斥的视图或时间范围之间切换。

## 何时用哪一种

| 控件 | 用在 | 例子 |
| --- | --- | --- |
| 筛选标签 | 过滤当前列表，结果是原列表的一部分 | 全部 / 已验证 / 待验证 / 被引用 |
| 分段选择 | 切换整页的视图或时间范围，选项互斥且不超过四个 | 近 7 天 / 近 14 天 / 近 30 天 |

## 规则

- 筛选放在工具栏里，搜索框之后；时间范围放在页头的操作位置，作用于整页。
- 一组筛选标签默认单选，“全部”在最前；需要多选时在标签组的悬停提示里说明。
- 选中的标签用 `surface-pressed` 底、去掉边框；选中状态写在 `aria-pressed` 上。
- 筛选后列表为空时显示“没有符合条件的知识”，并给出“清除筛选”。
- 网址记住筛选条件，刷新或分享链接后保持一致。
- 标签文字只写条件本身，不加数量；需要数量时写在事实行里。
