# Stat

统计数字：只有一个数要说时不画图，直接给数字，必要时配一条迷你柱状图或组成分段条。

## 结构

- 标签（`ch-stat-label`）：写清统计什么、哪个时段，例如“近 30 天被引用”。
- 数值（`ch-stat-value`）：正文字体 24px、字重 600，比例数字，不用等宽；千位分隔，单位前留一个空格（“3 次”“1.2 GB”）。
- 补充（`ch-stat-note`，可选）：一句事实，例如“其中 291 条已验证”“比上周少 6 条”。
- 迷你柱状图（`ch-spark`，可选）：12 个时段，当前时段用本页图表色，其余用 `chart-grid`；不画坐标。
- 组成分段条（`ch-parts`）：一个整体的几部分，高 8px，两端圆头，各部分之间 2px 间隙，下方是图例；每一段悬停显示名称、数量与占比。

## 规则

- 一组统计数字最多四个，放在同一行（`ch-stats`），窄屏时自动换行。
- 变化值写成事实句，不加箭头和红绿；需要表示好坏时用状态色并配文字。
- 时段跟随页头的时间范围；切换范围时标签里的时段一起变。
- 数字为零时照常显示 0，不隐藏。
