# Dialog

对话框：需要填写或确认后才能执行的操作，例如分享、分享到团队、收回分享、停用成员。

## 结构

- 遮罩 `ch-dialog`（`scrim`）+ 面板 `ch-dialog-panel`（`surface-3`、14px 圆角、`shadow-dialog`，最宽 560px）。
- 头部：标题写动作本身（“分享到团队”），右侧是关闭按钮。
- 内容：操作对象、需要填写的字段、检查结果（`ch-checklist`）、一句后果说明。
- 底部：次要按钮“取消”在左，主按钮在最右，文字是动作本身（“确认分享到团队”）。

## 两步确认

会影响他人或不能撤销的操作分两步：

1. 打开对话框时先做检查，每项显示“等待检查中”，完成后逐项给出通过、注意或未通过；
2. 全部检查完成且没有未通过的项时，主按钮才可点击；有注意项时写明后果，例如“分享后替换团队中的旧版本”。

可以撤销的操作不弹对话框，直接执行，再用消息提示提供“撤销”。

## 交互

- 打开后焦点落在第一个可填写的字段；没有字段时落在主按钮上。
- Esc 和关闭按钮等同于“取消”；点遮罩不关闭，避免误操作丢失填写内容。
- 焦点限制在对话框内；关闭后焦点回到打开它的按钮。
- 控制台不依赖脚本时用 `:target` 打开；有脚本时加 `is-open`。
- 出现动画 180ms，向上 6px 并淡入；系统开启“减少动态效果”时直接出现。
