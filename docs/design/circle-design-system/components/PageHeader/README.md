# PageHeader

列表栏顶部的页头：位置、标题、事实行和操作，下方可接一行工具栏。

## 结构

1. **位置**（`ch-crumbs`）：从区域到上一级，用“ › ”连接，每一级都可点击；区域首页不显示位置。
2. **标题**（`ch-title`，22px）：区域、范围或文件夹的名称。页面的用法说明不常驻，放在标题的悬停提示里（`ch-tip`）。
3. **事实行**（`ch-meta`）：只写事实，用“ · ”分隔，例如“已分享给 2 人 · 24 条知识 · 19 条已验证”“近 14 天 · 128 个任务 · 截至今天 10:30”。
4. **操作**（`ch-actions`）：在标题右侧，主操作放在最右，最多一个主按钮。会打开对话框的按钮带“…”。
5. **工具栏**（`ch-toolbar`）：搜索在左并占满剩余宽度，筛选标签随后；时间范围用分段选择，放在操作的位置。

## 规则

- 每页一个标题，不在标题旁放图标或区域色。
- 时间范围同时作用于本页所有统计数字、图表和表格；切换时事实行里的时段一起变化。
- 窄屏时操作折到标题下方，按钮顺序不变。
- 事实行不写“共有”“当前”之类的虚词，也不写说明性的句子。
