# Toast

消息提示：告诉操作的结果；成功的 3 秒后自动消失，失败的留到被关闭为止。

## 结构

状态圆点 + 一句结果 + 至多一个动作（文字按钮），失败时右侧加关闭按钮。出现在页面右下角，多条时自下而上堆叠，最多三条。

## 写法

| 结果 | 写法 | 动作 |
| --- | --- | --- |
| 成功 | “已分享到团队”“已移动到 部署笔记” | 可撤销的操作提供“撤销” |
| 失败 | “分享未完成：来源‘部署手册.pdf’无法打开。” | 给出处理入口，例如“查看来源”“重试” |
| 进行中（超过 10 秒） | “等待同步中” | 完成后替换为结果 |

## 规则

- 成功用 `role="status"`，失败用 `role="alert"`。
- 不道歉，不写“操作成功”这类空话，写清楚做成了什么。
- 失败信息写原因和处理办法；不显示错误码以外的内部信息。
- 鼠标悬停在提示上时暂停自动消失。
- 需要逐项说明的结果（例如批量操作部分失败）改在页面或对话框里列出，不塞进提示。
