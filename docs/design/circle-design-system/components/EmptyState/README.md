# EmptyState

空状态：列表、表格或文件夹里没有内容时，说明这里会出现什么，以及怎样得到第一条内容。

## 结构

标题（一句事实）+ 一到两句说明 + 一个主操作（可再加一个次要操作）。左对齐，放在原本列表的位置，外框用 `line-hairline`。

## 写法

| 情况 | 标题 | 操作 |
| --- | --- | --- |
| 还没有内容 | “这个文件夹还没有知识” | 新建、导入文件 |
| 搜索或筛选没有结果 | “没有找到‘令牌刷新’相关的知识” | 清除筛选 |
| 没有权限或对象不存在 | “无法打开这个文件夹” | 返回上一级 |
| 加载失败 | “知识列表未能加载” | 重试 |

## 规则

- 不写“暂无数据”，不放插画和表情符号。
- 没有权限和对象不存在用同一种写法，不透露对象是否存在。
- 说明句只写事实和下一步，不解释系统原理。
- 只读的成员看不到“新建”等操作时，空状态只保留说明。
