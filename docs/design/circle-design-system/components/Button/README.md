# Button

按钮：执行一个动作或打开一个对话框，按重要程度分为主要、次要、文字和危险四种。

## 种类

| 种类 | 类名 | 用在 |
| --- | --- | --- |
| 主要 | `ch-btn--primary` | 一个区域里最重要的动作，例如“新建”“编辑”“确认分享到团队”。每个页头、详情面板、对话框最多一个。 |
| 次要 | `ch-btn--secondary` | 其他常用动作，例如“分享…”“导入文件”。 |
| 文字 | `ch-btn--ghost` | 次要入口与只有图标的按钮，例如“版本记录”“复制链接”。 |
| 危险 | `ch-btn--danger` | 影响他人或不能撤销的动作，例如“收回分享”“停用”。 |

尺寸：标准 34px（`control-height`），小号 30px（`ch-btn--sm`）用于工具栏和表格行内。

## 状态

- 悬停：主要按钮变淡到 88%；其他按钮叠加 `surface-hover`。
- 键盘焦点：2px `focus-ring`，外扩 2px。
- 提交中：加 `aria-busy="true"`，显示转圈，文字不变，期间不能再次点击。
- 不可用：`disabled`，透明度 45%；需要说明原因时在悬停提示里写清楚。

## 用词

- 写动作本身：“新建”“分享到团队…”“确认分享到团队”，不写“确定”“提交”。
- 会打开对话框的按钮带“…”；直接执行的不带。
- 只有图标的按钮必须有 `aria-label`，并配同样文字的悬停提示。
