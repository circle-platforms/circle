# Chart

图表：柱状图比较数量，折线图看趋势；只有一个数时改用统计数字（Stat）。

## 结构

- 标题（`ch-figure-title`）说明画的是什么；下方事实行写范围、合计和截至时间。
- 两个及以上系列时，标题下方是图例（`ch-legend`；折线加 `is-line`）。
- 绘图区（`ch-plot` 内的 `ch-chart`）：横向网格、刻度、标记、直接标注。
- 悬停提示（`ch-chart-tip`）：数值在前、名称在后，每行前面是系列色短横线。
- “以表格查看”（`ch-tableview`）：同一份数据的表格，默认收起。

## 颜色

- 单系列：用本页区域对应的图表色 `--area-chart`（知识库 `chart-1`、任务 `chart-2`、工作流 `chart-4`），不画图例。
- 多系列：按固定顺序 `s1`…`s4` 取 `chart-1` 到 `chart-4`；筛选掉一个系列时其他系列不换色；超过四个合并为“其他”或改用表格。
- 表示通过、未通过的系列用状态色并配文字；同一张图里不与系列色混用。
- 文字（刻度、数值、名称、图例）一律用文字色，不用系列色。

## 标记

| 标记 | 规格 |
| --- | --- |
| 柱 | 宽不超过 24px，顶端 4px 圆角，底端平直贴基线；值为 0 时不画 |
| 线 | 2px，圆头圆角 |
| 端点 | 直径 8px，外圈 2px 底色描边 |
| 面积 | 系列色 10% |
| 网格 | 只画横线，1px 实线，`chart-grid` |
| 刻度 | 取整（0、10、20），`chart-axis` 等宽 11px |

## 交互

- 柱状图：每根柱子是一个悬停与键盘焦点目标，范围是整条柱带；悬停时其余柱子变淡。
- 折线图：竖向参考线吸附到最近的日期，提示里列出该日期全部系列的值；聚焦图表后用 ←→ 移动。
- 只标关键的数：最新值和最大值；其余数值在提示和表格里。
- 时间范围由页头统一控制；重新加载时图表保持原样并变淡（`is-loading`），不显示骨架屏。
- 不用饼图、环形图、双纵轴和逐条生长的动画。
