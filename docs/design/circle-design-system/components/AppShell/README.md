# AppShell

circle-hub 控制台每个页面共用的三栏框架：左侧导航、中间列表、右侧详情；Circle 工作台用同一个框架，见 WorkbenchShell。

## 何时使用

登录页以外的所有页面。新页面只往三栏里放内容，不另起布局。

## 结构

| 栏 | 类名 | 宽度 | 底色 | 放什么 |
| --- | --- | --- | --- | --- |
| 导航 | `ch-nav` | `nav-width` 232px | `surface-0` | 品牌、搜索、区域入口；当前区域展开出范围与文件夹 |
| 列表 | `ch-pane` | 自适应 | `surface-1` | 页头、工具栏、列表或表格 |
| 详情 | `ch-inspector` | `inspector-width` 380px | `surface-2` | 选中对象的全部信息与操作 |

外层是 `ch-app`。页面根元素加区域类：知识库 `area-knowledge`、工作流 `area-workflow`、任务 `area-task`；其他区域不加，强调色回落到中性灰。

## 规则

- 三栏之间只靠底色分级和 `line-hairline` 细线区分，不加阴影、外框或圆角卡片。
- 列表和详情联动：选中一行，详情随之更新，网址同时记住选中的对象。
- 没有选中对象时，详情栏显示本区域概况（数量、状态分布、最近变化），不留空白。
- 屏宽小于 1180px：详情不再常驻，点行进入详情页（外层加 `is-detail`），从页头的位置返回列表。
- 屏宽小于 760px：导航收为页首一行，列表与详情各占整屏，左右留 16px。
- 页面本身不横向滚动；宽表格在自己的区域内滚动。

## 用词

页面标题用区域或文件夹的名称，例如“接口规范”；位置写成“知识库 › 我的”，不用斜线。
