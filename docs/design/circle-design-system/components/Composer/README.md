# Composer

Circle 工作台的输入区：输入消息、选择模型与模式；外框的颜色说明 Circle 此刻的状态。

## 结构

- 外框 `ch-composer`：`surface-sunken` 底色、1px `line-control` 边框、10px 圆角；聚焦时边框变为 `focus-ring`。
- 输入框：正文 14px，随内容增高，最多 12 行后滚动。
- 底栏（`ch-composer-foot`）：知识库开关（筛选标签）、模型与强度选择（文字按钮）、模式文字（靠右）、发送按钮。

## 状态

| 状态 | 外框 | 说明 |
| --- | --- | --- |
| 默认 | 1px `line-control` | 可以输入并发送 |
| 计划模式 | 2px `brand-violet` | 模式文字变为“计划”，Circle 先给出计划再动手 |
| 工作中 | 2px 色环，3.6 秒转一圈 | 底栏显示“等待 Circle 完成中”与用时，发送按钮变为停止 |
| 等待回应 | 2px `brand-orange` | 上方出现请求提示条；回复后恢复默认 |

外框颜色变化用 180ms 过渡；系统开启“减少动态效果”时色环静止。

## 规则

- 色环只出现在这里和标志上，界面其他地方不用渐变。
- 发送按钮是唯一的主按钮（`inverse-surface` 底）；没有内容时不可用。
- 快捷键：Enter 发送，Shift+Enter 换行，Esc 停止当前这一轮（需确认时弹出确认）。
- 占位文字写示例动作，例如“描述一个改动，或提出问题…”，不写“请输入”。
