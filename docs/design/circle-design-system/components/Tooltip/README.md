# Tooltip

悬停提示：放补充说明、完整时间、图标按钮的名称和不可用的原因，页面上只常驻事实。

## 何时使用

| 用在 | 例子 |
| --- | --- |
| 页面或卡片标题的用法说明 | “任务读取这条知识的次数，按天统计。” |
| 只有图标的按钮 | “复制链接” |
| 简化后的时间 | “今天 10:24”悬停显示“2026-11-02 10:24:31” |
| 不可用的控件 | 说明为什么不能操作、怎样才能操作 |
| 被截断的文字 | 显示全文 |

## 规则

- 提示只做补充：其中的信息在页面别处或详情里也能找到，不能是唯一的入口。
- 一句话，最宽 260px，不放链接和按钮；需要操作时改用对话框或详情面板。
- 悬停或键盘聚焦时出现，离开即消失；出现时 120ms 淡入，不延迟。
- 默认出现在目标上方居中；目标贴近左边缘（例如页面标题）时加 `ch-tip--start`，与目标左对齐。
- 提示里的时段跟随页面选择的时间范围，例如切到“近 7 天”后提示也写“近 7 天”。
- 保留 `title` 或 `aria-describedby`，读屏软件能读到同样的内容。
