# ListRow

列表行：以阅读为主的列表，每行先给标题，再用一行事实说明类型、状态、来源数量和时间。

## 结构

- 左侧标记位（`ch-row-mark`）：选中时显示区域色圆点；批量模式下换成勾选框。
- 标题（`ch-row-title`）：一句完整的陈述，最多两行。
- 事实行（`ch-row-meta`）：类型标签 → 行内状态 → 数量 → 时间（靠右，等宽小字）。

## 交互

- 点行即选中（`is-selected`：区域色淡底加细描边），右侧详情同步更新，网址记住选中对象。
- ↑↓ 移动选中，Enter 在窄屏下打开详情页。
- 悬停叠加 `surface-hover`；行内不出现按钮，操作在详情面板里。
- 批量：只有支持批量操作的列表显示勾选框。勾选后列表上方出现批量操作条（`ch-bulkbar`），写明“已选 2 条”和可做的操作；不能勾选的行把勾选框置灰，并在悬停提示里说明原因。
- 加载更多时保留已显示的行，在末尾追加，不跳回顶部。

## 用词

时间按“今天 10:24 / 昨天 / 10-30 / 2025-12-01”逐级简化，悬停显示完整时间。数量写“来源 2”，不写“2 个来源已关联”。
