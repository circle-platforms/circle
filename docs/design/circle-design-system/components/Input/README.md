# Input

输入框：搜索、单行文本、多行文本和下拉选择共用的外框，配标签、提示和错误信息组成字段。

## 结构

- 外框 `ch-input`：凹下的底色 `surface-sunken`，1px `line-control` 边框，高 34px，圆角 8px。图标、快捷键提示（`ch-kbd`）都放在外框里。
- 字段 `ch-field`：标签（`ch-field-label`）在上，输入框居中，提示（`ch-field-hint`）或错误（`ch-field-error`）在下。

## 状态

| 状态 | 外观 |
| --- | --- |
| 默认 | `line-control` 边框 |
| 聚焦 | 边框变为 `focus-ring`，外侧再加一圈淡色光晕 |
| 出错 | 字段加 `is-invalid`，边框变为 `status-fail`，下方写错误信息，输入框加 `aria-invalid` 与 `aria-describedby` |
| 不可用 | 透明度 45%，文字不可选 |

## 规则

- 每个输入框都有标签；搜索框可以只用 `aria-label`，占位文字写出搜索范围，例如“在接口规范中搜索”。
- 占位文字只是示例，不能代替标签。
- 错误信息写清问题和处理办法，在离开字段或提交时出现，不在输入过程中逐字报错。
- 必填项不加星号；可选项在标签后写“（可选）”。
