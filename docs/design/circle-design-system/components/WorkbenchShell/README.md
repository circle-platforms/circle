# WorkbenchShell

Circle 工作台的三栏框架：左侧导航、中间会话、右侧抽屉。它与控制台的 AppShell 是同一个框架，宽度、底色和分隔方式完全一致。

## 结构

| 栏 | 宽度 | 底色 | 放什么 |
| --- | --- | --- | --- |
| 导航 | 232px | `surface-0` | 色环、小写字标“circle”与“工作台”字样、工作区选择、新会话与搜索、会话列表、“平台”与“Circle”两组页面入口、运行状态 |
| 会话 | 自适应，内容最宽 760px 居中 | `surface-1` | 会话标题与操作、消息、思考、工具调用、计划、请求提示、输入区、状态行、后台任务 |
| 抽屉 | 380px | `surface-2` | 上下文、文件、改动、任务、网页等标签页；顶部是标签与关闭按钮 |

## 会话里的元素

- **用户消息**：靠右的 `surface-2` 圆角块（10px），不加边框。
- **Circle 的回复**：直接排在底色上，前面是小号色环与小写的“circle”。
- **思考**：次要文字，前面标“思考”，不加竖线或框。
- **工具调用**：`surface-2` 的单行，图标、动作、对象（等宽）与用时；展开后显示详情。
- **计划**：`surface-2` 的块，已完成的步骤用通过色圆点，当前步骤用紫色圆点并加粗。
- **请求提示**：细线框的一行，注意色圆点加“3 个请求等待处理”，右侧“查看”。
- **输入区**：见 Composer。
- **状态行与后台任务**：等宽小字；后台任务每行一个状态圆点、编号、命令或说明与用时。

## 规则

- 导航项用 Lucide 图标加文字；当前会话用 `surface-hover` 底和 600 字重，不用彩色。
- 会话里不出现卡片套卡片；同一层级的块（工具调用、计划）用同一种底色。
- 抽屉宽度可拖动，最窄 300px；窗口小于 1180px 时抽屉收起为按钮。
- 运行状态（已连接 · {连接名}、运行时已停止）放在导航底部，用状态圆点加文字。
