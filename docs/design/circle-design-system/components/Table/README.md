# Table

表格：需要按列比较、排序或扫读数字时使用；以阅读为主、每行信息少于四项时改用列表（ListRow）。

## 结构

- 外框 `ch-table-wrap`：10px 圆角、`line-hairline` 细线，表格宽于容器时在框内横向滚动。
- 表头：`label` 样式（12px、500、字距 0.04em、`text-tertiary`），不加底色。
- 行与行之间一条 `line-hairline`；不画竖线，不做斑马纹。

## 对齐与格式

| 内容 | 对齐 | 格式 |
| --- | --- | --- |
| 文字 | 左对齐 | 过长时单行省略，悬停显示全文 |
| 数字（`num`） | 右对齐 | 等宽数字，千位分隔：1,284；大小写 1.2 GB |
| 时间（`nowrap`） | 左对齐 | 今天 10:24 / 昨天 / 10-30 / 2025-12-01，不折行 |
| 状态 | 左对齐 | 圆点加文字 |

## 交互

- 可排序的列在表头加 `aria-sort`，并显示 ↑ 或 ↓；点击切换升降序，网址记住排序。
- 点行选中（`is-selected`），详情面板同步更新；行内不放按钮。
- 悬停叠加 `surface-hover`。
- 行数多时分页或滚动加载，表头固定在顶部。
- 没有数据时用空状态（EmptyState）替换整个表格，不显示空表头。
