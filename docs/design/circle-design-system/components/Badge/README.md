# Badge

状态与标注：状态标签（`ch-badge`）、行内状态（圆点加文字）、类型标签（`ch-tag`）和数量（`ch-count`）。

## 何时用哪一种

| 形式 | 用在 | 例子 |
| --- | --- | --- |
| 状态标签 | 详情面板顶部、对话框里的检查结果，需要醒目时 | 已验证、未通过、等待判定中 |
| 行内状态 | 列表行与表格单元格，一行里有多项信息时 | ● 已通过 |
| 类型标签 | 对象的类型，中性灰外框 | 接口行为、概念、操作步骤、经验 |
| 数量 | 导航与分区标题旁的计数，等宽小字 | 24 |

## 状态与颜色

| 类别 | 类名后缀 | 例子 |
| --- | --- | --- |
| 通过 | `--pass` | 已验证、已通过、已合并、已发布 |
| 失败 | `--fail` | 未通过、已拒收、已撤回 |
| 注意 | `--warn` | 已被取代、即将超额、多处匹配 |
| 进行中 | `--info` | 运行中、等待判定中、等待补充材料中 |
| 待定 | `--pending`（空心点） | 待验证、未检查、未知 |

## 规则

- 状态永远带文字，不能只靠颜色；圆点只是辅助。
- 状态文字用界面用语里的标准说法，进行中写成“等待××中”。
- 类型标签不着色；区域色和状态色都不用在类型标签上。
- 一个对象只显示一个状态标签；需要说明原因时放在悬停提示里。
