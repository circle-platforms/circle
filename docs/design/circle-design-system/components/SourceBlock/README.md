# SourceBlock

来源块：说明一条知识或一个结论依据什么，先写文件和位置，再给原文摘录和“打开原文”。

## 结构

- 外框 `ch-source`：`surface-1` 底色、10px 圆角、`line-hairline` 细线；放在详情面板（`surface-2`）上，比面板低一层。
- 头部（`ch-source-head`）：左边是“文件名 · 位置”，右边是动作或状态。
- 摘录（`ch-quote`）：原文的一句或几句，用「」括起，13px、行高 1.65、`text-secondary`。

## 来源的写法

| 来源 | 写法 | 动作 |
| --- | --- | --- |
| 文件 | 错误码对照表.xlsx · 第 12–14 行 | 打开原文 |
| 另一条知识 | 知识：会话的有效期 | 查看 |
| 无法定位或多处匹配 | 文件与位置照写，右侧换成状态标签（未定位 / 多处匹配） | 下方给出处理办法 |

## 规则

- 不显示哈希、引用编号、内部路径或版本号。
- 摘录保持原文，不改写、不翻译；过长时显示前三行，可展开。
- 来源数量写在分区标题里：“来源 · 3”。
- 无法打开的来源和已删除的来源看起来一样，都写“无法打开”，不区分原因。
