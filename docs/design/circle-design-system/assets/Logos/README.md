# Logos

两个标志，同一组颜色：

- `circle-mark.svg`：Circle 的标志，色环，蓝 → 紫 → 红 → 橙，再回到蓝；取自 Circle 仓库 `docs/images/logo.svg`。工作台左上角用它，界面里画作 `ch-logo`（四个品牌色的圆锥渐变，中间挖空成底色）。
- `circle-hub-mark.svg`：circle-hub 的标志“轨道”（所有者决定 82），中心一点与轨道用文字色，四颗卫星依次是蓝、紫、红、橙；取自 circle-hub 的 `/console/favicon.svg`，随系统深浅色切换墨色。控制台左上角用它，界面里画作 `ch-hubmark`。

用法：

- 最小尺寸 16px；四周至少留出标志宽度四分之一的空白。
- 不改颜色、不加描边或阴影、不拉伸、不旋转；不单独拿其中一种颜色当标志。
- 字标一律小写：“circle”“circle-hub”。
- 文件里的颜色是深色底的取值；浅色底上的橙色按 `brand-orange` 加深到 3:1，与 Circle 终端的画法一致。
