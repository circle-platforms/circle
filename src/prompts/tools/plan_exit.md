Ask the user what to do with the finished plan. Call it once the plan file holds the whole plan and your questions are answered, never before the plan is written.

The user picks one:
- implement in auto mode, or implement with manual approval: plan mode ends; implement the plan.
- change the plan: you get what to change; revise the plan file, then call plan_exit again.
- save the plan only: plan mode stays on and nothing changes; end your turn.

Call this tool instead of asking in your reply whether to implement the plan.
