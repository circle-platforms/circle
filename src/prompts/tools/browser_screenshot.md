Look at the page in this conversation's browser as an image: the shown tab, without the rest of the screen.

Usage:

- Use it when the layout or a picture matters; the snapshot is the way to read text and find elements.
- It does not ask the user: it shows only this browser.
- To save the page as a PNG for later upload without sending the image to the model, set `save_only` to true. The result gives the local path; this also works when the model cannot read images.
