Use it when the user asks for a plan, or when a request should be planned first: it touches many files, has several possible approaches, or needs decisions from the user.

Do not use it for a small, clear task, or when the user wants the change made now.

In plan mode you can read, search and explore, and write only the plan file the system prompt names. `plan_exit`, or the user, ends it.
